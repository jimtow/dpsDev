If by "GitHub folder" you mean a repository that already exists on GitHub, 
the best way is to clone it directly to your Desktop.

Option 1: Clone the repository to your Desktop (recommended)
Open VS Code or a terminal.
Change to your Desktop folder.

Windows Command Prompt:

cd %USERPROFILE%\Desktop

PowerShell:

cd ~/Desktop
Clone the repository:
git clone https://github.com/USERNAME/REPOSITORY.git

For example:

git clone https://github.com/jimtow/dpsDev.git

Git will create a new folder on your Desktop named after the repository.
